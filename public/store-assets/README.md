# 스토어 제출용 이미지

| 파일 | 규격 | 용도 |
|------|------|------|
| `app-logo.png` | 600×600 | 앱 로고 (필수) |
| `app-logo-dark.png` | 600×600 | 다크 모드 로고 (선택) |
| `thumbnail.png` | 1932×828 | 썸네일 (필수) |
| `screenshot-portrait-1~3.png` | 636×1048 | 세로 스크린샷 ×3 (필수) |
| `screenshot-landscape-1.png` | 1504×741 | 가로 스크린샷 ×1 (필수) |

## 재생성

```bash
npm run store-assets
```

## 웹에서 다운로드

배포 후 `/store-assets` 페이지에서 개별 다운로드 가능.
